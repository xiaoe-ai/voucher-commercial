# Install into Commercial Voucher

Recommended location:

docs/xiaoe/XIAOE_PORTABLE_CORE.md

Optional:
docs/xiaoe/PORTABLE_MANIFEST.json

Use this package as Commercial Voucher's XiaoE operating constitution.

Do NOT:
- copy XiaoE Core Supabase secrets
- copy XiaoE Core Runtime Key
- point Commercial directly at XiaoE Core database
- replace Commercial business tables/functions with XiaoE Core tables/functions

Commercial remains independent; XiaoE rules govern how work is performed.
